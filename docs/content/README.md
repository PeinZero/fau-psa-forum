# Starter content

Eight verified starter threads and two guides for the launch. Each thread lists its official
sources and ends with "Last checked: October 2026"; every amount carries an "as of" date.

- `threads/*.md`: one thread per file. Front matter: `title`, `category` (category slug),
  `city` (`erlangen`, `nuremberg`, `both` or `null` for not city-specific). The rest is the
  markdown body.
- `guides/*.md`: front matter `slug`, `title`, `summary`, `is_featured`, `sort_order`. Each
  `## ` heading is a step in order; the line `thread: <exact thread title>` links the step to
  that thread, and the text below it is the step body.
- `build-seed.py`: turns these files into `supabase/seed/initial_content.sql`.

## Review

1. Read each thread and open its sources. Fees, the blocked-account amount, insurance
   contributions and the Nuremberg office move (Stadthaus Q from 30 November 2026) are the
   most likely to change.
2. Edit the markdown, not the SQL, then regenerate:

   ```sh
   python3 docs/content/build-seed.py .
   ```

   The script checks category slugs, cities, title and body lengths, and that every guide step
   names an existing thread title.

## Load

Already loaded on the live database by migration `20261028100000_launch_content_reset.sql`, which
removes the pre-launch test content (everything created before 25 October 2026 except the starter
content) and inserts these threads and guides. It skips the content step on databases without the
owner account (local, CI). Both guides are featured on Home (`is_featured: true`).

To load content into another database, or after editing it, run `supabase/seed/initial_content.sql`
in the Supabase SQL editor (generated by `build-seed.py`):

- Threads are inserted as `published` with the owner account as author and reviewer; the script
  stops with an error and inserts nothing if that account has not signed in yet.
- Threads whose title already exists and guides whose slug already exists are skipped, so running
  it again is safe. A changed title counts as a new thread.
- `supabase/seed/cleanup_test_content.sql` is the standalone version of the test-content cleanup
  (preview instructions at the top of the file).
- Optional: mark each thread verified as a moderator for the "Verified Oct 2026" badge.
